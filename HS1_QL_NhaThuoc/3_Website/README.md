# Website QL_NhaThuoc — bản chuẩn bị (chưa xây)

Theo bảng phấn: Folder → 1) Bản thiết kế → 2) Database → 3) Website → 4) Bảng list prompt AI.
Bước này mới chuẩn bị; chưa viết code website cho đến khi nhóm xác nhận.

## Trang dự kiến
| Trang | Chức năng | Người làm |
|---|---|---|
| Thuốc, Nhóm thuốc, Lô thuốc | Danh sách, thêm/sửa/xóa, tìm theo tên, sắp xếp theo tên | Hùng |
| Nhà cung cấp, Phiếu nhập | Danh sách, tìm theo ngày, sắp xếp theo ngày | Thi |
| Khách hàng, Nhân viên, Hóa đơn | Bán hàng, tính tổng tiền | Nguyên Anh |
| Báo cáo | Doanh thu theo ngày, tồn kho, thuốc sắp hết hạn | cả nhóm |

## Cần nhóm chọn trước khi xây
- Công nghệ: đề xuất PHP + MySQL (dễ chạy ở trường) hoặc Node.js + MySQL.
- Máy chạy: XAMPP trên máy tính, hay dịch vụ trực tuyến.
